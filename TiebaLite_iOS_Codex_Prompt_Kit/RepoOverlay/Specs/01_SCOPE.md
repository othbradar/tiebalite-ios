# 范围与优先级

## P0：必须完成并稳定

- App Shell：Tab、iPhone NavigationStack、iPad NavigationSplitView、深链 route 基础。
- 推荐流：首次、刷新、分页、错误、状态保持。
- 帖子阅读：标题、作者、楼层、楼中楼、文本、图片、链接、表情及已识别内容节点的只读渲染。
- MediaViewer：打开、左右切换、双击/捏合缩放、失败占位、关闭返回。
- 关注的吧：登录/未登录、加载、刷新、进入吧首页。
- 吧首页：吧信息、主题列表、置顶/普通主题、排序或分区、分页、返回保持。
- Session：安全存储、过期、退出、清理。
- iPadOS：全屏、横屏、常见分屏宽度。
- 可访问性、深色模式、Dynamic Type、Reduce Motion。
- 自动化 fixture、状态测试、关键 UI smoke tests。

## P1：核心稳定后实现

- 搜索吧/主题。
- 浏览历史。
- 用户资料只读页。
- 字体大小、图片策略、主题等设置。
- 收藏/关注的只读展示；任何远端写入仍排除。
- 外链打开和分享。

## 明确排除

- 签到和一键签到。
- 发帖、回帖、楼中楼发布。
- 删除、点赞、关注/取消关注等远端写操作。
- 推送通知。
- 绕过平台认证、安全或付费限制。
- 首个版本中的复杂自定义转场、下滑关闭、花哨弹簧动效。

## 内容节点策略

阶段 01 必须从 Android 的 Protobuf 与内容渲染代码生成完整矩阵。每个节点标记：

- Supported：生产级渲染。
- Degraded：安全降级并保留文本/链接语义。
- Unsupported：显示明确占位，不崩溃、不吞掉相邻内容。
- Unknown：证据不足，禁止猜测字段。
