# Endpoint evidence checklist

- User task and repository method.
- Android source file and symbol.
- HTTP method and URL family.
- Query/form/protobuf encoder and content type.
- Request message and field sources.
- Authentication/cookie capability.
- Response message and server error fields.
- Pagination cursor/page semantics and de-duplication ID.
- Missing field/unknown enum behavior.
- Sanitized fixture provenance.
- Swift endpoint, mapper and tests.
- Remaining UNKNOWN and safe experiment.
