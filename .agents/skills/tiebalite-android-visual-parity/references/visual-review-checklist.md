# Visual review checklist

- [ ] No extra product title below the navigation title.
- [ ] No giant rounded card around each row/floor.
- [ ] Avatar/forum icon is real or uses a neutral failure placeholder.
- [ ] Level chip comes from real data.
- [ ] Text hierarchy and line limits match Android reference.
- [ ] Adjacent rows use a thin divider.
- [ ] Multiple images are grouped, not emitted as one full-width row each.
- [ ] Inline subposts show at most three.
- [ ] Root tabs and page tabs match the Android hierarchy.
- [ ] Current screen scrolls smoothly.
- [ ] iPhone screenshot captured.
- [ ] iPad screenshot captured when layout is affected.
- [ ] App left open for user review.
- [ ] No commit before approval.
