# Minimum interaction matrix

- Main tabs preserve independent paths and state.
- Push/pop and system edge back.
- Refresh and pagination while content remains visible.
- Open detail, return, and preserve list anchor.
- Pager: 20 fast swipes, half-cancel, reverse, data update, rotation/resize.
- Media: loading/failure, double-tap, pinch, pan, zoom-to-page arbitration, first/last page, close/return.
- Safe area: toolbar, bottom inset, sheet/full screen, keyboard when applicable.
- iPad: full screen, landscape/portrait, half width, narrow collapsed split.
- Appearance: dark, accessibility text size, Reduce Motion.
- Network: slow, failure, stale response and cancellation.

Watch specifically for transparent exposure, one-frame white backgrounds, duplicate pages, wrong index, stale overlay, blocked back gesture, content under bars, jump-to-top and inconsistent motion.
