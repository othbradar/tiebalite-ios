# v0.2.0beta8 — 回复通知与帖子内容修复

修复从“回复我的”进入帖子后只显示被点击的回复，以及随后从吧首页打开同帖仍缺少主楼和其他楼层的问题。

## 本版更新

- 通知定位后加载目标所在的正常分页，同时保留定位、相邻楼层、后续分页和回到首楼。
- 定位得到的局部回复不再覆盖整页缓存；旧版留下的局部缓存会在读取时确认并修复，保留已有阅读位置。
- 页面加载失败可重试，中途退出后可继续恢复；保留原有回复成功回显、滚动优化、楼中楼两步回复及图片功能。
- 已验证的 iOS 发帖、回复和上传链路保持不变。

## 版本与安装

- 发布标签 **v0.2.0beta8**；IPA 内 App 版本 **0.2.2 / Build 21**。
- 支持 **iOS/iPadOS 18.0+**、iPhone/iPad、ARM64。附件为完整真机 Release **未签名 IPA**，需使用 SideStore 或既有工具自行签名。
- 沿用原 Apple ID/Team 和签名后的 Bundle ID 覆盖安装；不要先卸载旧版。
- SideStore 继续使用[原订阅源](https://raw.githubusercontent.com/othbradar/tiebalite-ios/main/sidestore/source.json)。本版实际版本由 0.2.1 升至 0.2.2；源同步后刷新 Sources，再到 My Apps 检查 Update。签名刷新不等于安装新版。

## 验证范围

- 49 项相关单元回归、iPhone/iPad 定向通知 UI 检查通过；正常 Live App 已检查通知定位、相邻回复、回主楼和普通入口重开。
- 设备 Release 归档、生产/测试代码隔离、资源、ARM64 架构、包内版本及 IPA 完整性检查通过。
- 完整门禁仍有已记录的本机工具链及历史仓库检查失败，不表述为全量测试通过。具体范围见[修复审计](https://github.com/othbradar/tiebalite-ios/blob/main/Docs/Audits/NOTIFICATION_THREAD_CONTEXT_FIX_2026_10_28.md)。本版未在物理设备亲测 SideStore 更新提示或全部发送场景。
