# TiebaLite iOS v0.2.0beta2 — 阅读缓存与图片体验更新

本版汇总已验收的 U01–U06，保留 Android TiebaLite 风格和现有虚拟列表。

## 阅读与加载

- 记住吧首页排序选择；重进先展示缓存，再自动检查更新，支持下拉刷新。深处阅读静默保留，回到顶部应用更新，不显示“有新内容，点击更新”提示。
- 缓存帖子及已加载分页，返回重进和进程重开可恢复阅读楼层；首次定位完成后交还正常阅读控制，新阅读位置可以保存。
- 有界内容预载最多两个投机请求，用户点击优先；同键进行中请求可复用，取消预载不取消前台已接管的请求，不写入历史或阅读位置。

## 图片查看与保存

- 看过的可缓存图片可在重启后从磁盘读取；同一资源共享下载，单个使用者取消不影响其他订阅者，清晰度和显示尺寸分别管理。
- 原始倍率左右滑动切图，放大后支持斜向自由拖动和捏合。顶部保留关闭与居中张数，移除切图箭头。
- “加载原图”按需提升当前图片清晰度，保持倍率和查看位置；成功后按钮隐藏，失败保留已有画面。
- 原始倍率长按图片可保存图片或分享／存文件，操作按钮不再常驻底部。保存使用接口已有原图候选的编码文件，无原图时明确失败，不把缩略图重新编码冒充原图。
- 相册只申请添加权限；分享使用实际图片文件，临时文件在完成或取消后释放。设置可清图片缓存，不删除账号、历史、排序、阅读位置或草稿。

## 验证事实

- 受控缓存重建后断网读取已缓存图片：源请求0次；两个消费者请求同一资源：源请求1次，取消其中一个仍可完成。
- 受控同键内容预载与前台接管：源请求1次；U04 Live 合并计数为0，未将测试结果冒充实网合并。
- Live 进程重开后加载原图：新增网络请求0次、磁盘命中1次。保存／分享文件保持取得的原始编码字节，不以图片尺寸判定原图。
- 相关 Unit、iPhone/iPad 短 UI 和 Simulator 人工验收通过；详见 TASK_STATE 与本版发布构建记录。未重复全量测试或长期压力矩阵。

## 下载与安装

- 标签：`v0.2.0beta2`；App 版本：`0.2.0`，Build `3`。
- 支持 iOS/iPadOS 18.0 及以上，iPhone/iPad，arm64。
- 附件为 **真机 Release 未签名 IPA**，沿用上一版分发方式；安装前需要自行签名。不是 Simulator、App Store 或 TestFlight 包。
- 使用附件 `SHA256SUMS` 核对下载文件。发布包不含用户账号、缓存、历史、草稿、测试 Fixture 或调试入口。

## 已知限制

- **iPad 旋转进入分栏后回首楼尚未修复**；本次获准不阻塞后续开发，不将其标为通过。
- 真机相册尚未验收，签名团队未配置；Simulator 检查不等于真机检查。
- 原图显示仍受4096像素解码预算限制；动图查看只保证静态帧，保存／分享保留下载得到的动图数据。未知或受保护资源不会盲目持久化。
- 私有接口与服务端审核仍可能变化；先前回复成功不保证持续可见，完整写入目标与多图实网矩阵未覆盖。
- 不包含 U07 及后续阶段，未增加批量下载或新的导航结构。
