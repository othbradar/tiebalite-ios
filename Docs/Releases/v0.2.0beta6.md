# TiebaLite iOS v0.2.0beta6 — 回复入口、搜索与淡蓝图标

本版汇总 beta5 之后已验收的 P01–P04，保留现有账号、草稿、缓存与发帖/回复/上传链路。

## 回复与阅读

- 点击主帖楼中楼预览的文字或背景，进入对应父楼的独立楼中楼页面；只有1–3条子回复也能进入，主帖最多预览3条。
- 在独立页面点击具体子回复正文即可打开回复编辑器，正确选择该条回复及其作者；保留复制、图片和链接的独立动作。
- 移除蓝色“查看全部N条回复”和灰色“回复”入口；普通楼层正文也支持点击打开回复编辑器。
- 楼层、日期和地区移到正文底部，缩短顶部空白；楼中楼同步调整。
- 帖子回复区改为“全部回复 / 只看楼主”及“热门 / 正序 / 倒序”控件，两组选择全局记忆，使用更小字体和扁胶囊。
- 吧首页帖子移除重复的吧名标签。

## 搜索

- 全局搜索按 Android TiebaLite 样式提供搜吧、搜帖和搜人，复用首页搜索框；搜帖可选新帖在前、旧帖在前和相关度。
- 修复从搜人进入个人主页后，首次账号资料读取失败导致关系、主题和关注吧无法恢复的问题。
- 吧内搜索限定当前吧，支持只看主题/只看评论、新帖在前/相关在前；空输入展示可复用的本地搜索历史。
- 吧内搜索使用完整原生导航页面，保留结果分页、返回位置及系统滑动返回；修复取消按钮白块和搜索框顶部在转场时短暂裁切的问题。

## 图标

- 按用户选择采用 Android TiebaLite 的帖子卡片造型，改为淡蓝色，并保留可编辑矢量源及来源说明。
- iPhone 与 iPad 模拟器均已覆盖安装，检查真实主屏图标及正常首页。

## 下载与安装

- 标签 `v0.2.0beta6`；App版本 `0.2.0`，Build `19`。
- 支持 iOS/iPadOS 18.0及以上，iPhone/iPad，arm64。
- 附件为**真机 Release 未签名 IPA**，安装前需自行签名；不是 Simulator、App Store 或 TestFlight 包。
- 同时提供 `SHA256SUMS`。升级请保留原签名身份及 Bundle ID 覆盖安装，避免卸载造成数据丢失。

## 验证与已知限制

- P01–P04 均由用户逐阶段验收；复用对应状态/映射及 iPhone/iPad 定向回归，纯图标阶段检查资源、构建与真实主屏。发布另外校验设备 Release 归档、调试内容隔离、IPA结构及SHA256。
- 未重跑全量业务或物理设备矩阵。真实发送仍由用户执行；本版没有修改已验收的 iOS 写请求、上传、签名或账号准备链路。
- 子回复搜索结果进入正确父楼的楼中楼页面，尚不自动滚动到具体子回复。
- 个别用户资料的服务端拒绝、私有 SDK/Passport、安全验证续发、正文缓存独立清理入口及其他 beta5 已列缺口仍保留。
- 真机、iOS18主屏及系统着色/深色图标模式未完成本轮验证。
