# TiebaLite iOS 0.2.0 Beta 1 — 页面重制与功能更新

本版汇总 R01–R13 的 Android TiebaLite 视觉一致性整改，以及最新的发帖/回复显示名修复。相比 0.1.0 Beta 3，主要更新如下。

## 新增功能

- 完整楼中楼回复页面，支持独立分页；帖子内保留前三条子回复预览，可打开全部回复。
- 新帖、主题回复、楼层回复、楼中楼回复编辑器；支持会话内草稿、最多 9 张图片选择与上传、官方表情选择及正文内联显示。
- “回复我的”和“提到我的”消息列表、未读计数；点击引用进入主题，点击具体消息进入完整帖子并定位对应一级楼层，楼中楼消息定位父楼。
- 首页最近浏览的吧、真实账号头像、用户/吧头像、接口提供的等级与统计；补齐账户资料、浏览历史、搜索和设置入口。
- 内置 132 张表情资源，完善正文、子回复和编辑器中的官方表情、链接、文字选择与复制。

## 页面重制

- 重制首页、动态、吧首页、帖子、楼中楼、消息和“我的”等页面，采用平面列表、细分隔线、紧凑元数据与小型等级标识。
- 统一真实头像、中性加载/失败占位、1–8 张图片的紧凑网格，保留原图片查看器的缩放与多图切换。
- 吧首页支持最新排序、精华与接口返回的真实分类；帖子顶部固定吧头像/名称入口，日期统一中文显示。
- 进入吧首页和帖子时隐藏根底栏，修正底部白色占位；修正右滑返回时顶部名称与返回按钮的转场方块。
- iPad 竖屏采用与手机接近的单列阅读，横屏保留多列布局；修正切换“我的”残留旧帖子的问题。

## 修复与稳定性

- 动态列表接入既有高性能虚拟列表，修正深滚动后切换根页面卡住的问题，保持分页、图片复用与返回位置。
- 修正吧首页首个标签内容区右滑返回、关注吧列表末行遮挡、消息定位楼层及表情面板宽度/键盘切换问题。
- 发送前读取并校验当前账号的真实显示名，补齐发帖/回复请求遗漏的 name_show；用户已确认修订版的一次文字加表情回复成功并可见。
- 保留断网刷新时的已有内容，恢复网络后可重试；Release 排除测试 Fixture、调试入口和私人截图。

## 下载与安装

- 版本：0.2.0，Build 2；支持 iPhone / iPad，iOS / iPadOS 18.0 及以上。
- 附件为 **arm64 真机、Release 配置、未签名 IPA**，不是 Simulator 包；安装前需使用自己的签名方式重新签名。
- 本版不是 App Store 或 TestFlight 分发包。源码和第三方来源说明随本 Release 对应标签提供。

## 已知限制

- 私有接口及平台审核可能变化。此前有回复被“涉嫌异常行为”删除；本次发送成功尚不能保证后续持续可见，也不能证明显示名是唯一原因。新帖、所有回复目标和多图实网发送尚未完成全矩阵验证。
- 未知或缺失原图的表情、服务端仅返回的“[图片]”文本仍原文降级；动图只保证可用静态帧。
- 未实现签到、点赞、删除、私信、系统推送、收藏及离线下载；已有计数不代表支持对应写操作。
- 真机完整 VoiceOver、iOS 18.x runtime 与完整 Stage Manager 设备矩阵尚未覆盖。
