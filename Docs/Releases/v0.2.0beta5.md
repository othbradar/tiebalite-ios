# TiebaLite iOS v0.2.0beta5 — 收藏同步、动态、媒体与内容操作

本版汇总 beta4 之后已验收的 U09–U15 更新，保留现有外观、草稿、登录、内容缓存与发帖/回复/图片上传链路。

## 新功能与改进

- 长帖阅读支持只看楼主、正序/倒序、跳页及继续上次阅读，分别保存查询模式与阅读位置。
- 新增云端收藏及同步、本机帖子/楼层书签；收藏列表使用与吧首页一致的帖子样式。
- 动态接入关注与热榜，保留各页独立的列表、缓存和阅读位置。
- 用户资料支持主题、自己的回复、关注的吧、关注与粉丝列表；增加关注关系操作和本机屏蔽。
- 视频直接在帖子原位置播放，设置可选点击或自动播放；增加语音与有界 GIF/WebP 动画播放，离页、滚出或进入后台停止播放。
- 支持帖子/楼层点赞与取消；本人主题、楼层和子回复可经确认后删除，成功后同步本地列表与缓存。

## Bug 修复

- 修复倒序查看报“无法跳转”的问题。
- 修复收藏空态图标过大及收藏帖子展示与吧首页不一致的问题。
- 修复此前 iPad 方向配置导致的自动旋转异常。
- 修复关注的吧加载兼容问题；成功响应但无可展示列表时使用中性提示，不再直接显示“加载失败”，不臆断具体隐私原因。
- 修复视频单独弹出播放器窗口的问题，恢复原位播放。
- 修复普通主题与楼层的点赞对象类型不匹配、服务端返回错误3280005的问题。
- 完善删除后旧分页、预载与缓存重新显示已删内容的处理，并校验账号与内容归属。

## 验证范围

- 用户已逐阶段确认倒序、收藏/同步、关注/热榜、用户列表、帖内视频及点赞等入口可用；未代替用户执行真实发送、关注、点赞或删除。
- U15 定向回归通过161项单元测试；iPhone 12项UI中一项旧测试定位失败，更新定位并保留全部行为断言后复验通过；iPad 4项通过。
- 正常模拟器已检查排序、分页、多图保存、返回重入、进程重建后的阅读恢复及iPad往返。测试通过不等于全部物理设备或服务端分支已验证。
- 发布使用设备 Release 归档，校验调试/测试内容隔离、版本、架构、IPA ZIP与SHA256；详细结果见构建记录。

## 下载与安装

- 标签 `v0.2.0beta5`；App版本 `0.2.0`，Build `18`。
- 支持 iOS/iPadOS 18.0及以上，iPhone/iPad，arm64。
- 附件是**真机 Release 未签名 IPA**，安装前需自行签名；不是Simulator、App Store或TestFlight包。
- 同时提供 `SHA256SUMS`。IPA不包含账号、草稿、历史、缓存、测试Fixture或调试入口。
- 升级时保留原签名身份及Bundle ID覆盖安装，避免为升级卸载或清理数据。

## 已知限制

- 设置已有图片缓存占用与清理，但正文内容缓存的独立占用/手动清理入口尚未接入。
- 私有SDK/Passport及验证码/安全验证续发按约定跳过；不宣称与官方客户端全部行为一致，也不保证服务端审核留存结果。
- 真实贴吧语音样本不足，媒体超出预算或编码不受支持时降级；未覆盖所有真实删除场景、关注关系写入分支及完整真机/Stage Manager矩阵。
- U14曾出现的偶发点赞失败随后恢复，具体原因仍未确认，不能认定所有此类提示已消除。
- 投票提交、签到、私信、系统推送和批量离线下载不在本轮；此前已记录的图片发送策略差异仍保留。
