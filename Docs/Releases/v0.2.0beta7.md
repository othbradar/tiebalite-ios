# v0.2.0beta7 — 帖子滚动流畅性更新

本版包含 P05 和 SF-00～SF-08 的帖子阅读性能修复。用户已在实机测试候选包，反馈慢速滚动比之前顺滑。

## 主要更新

- 修复帖子 Cell 复用期间出现的半秒停顿，以及带图楼层滚动时的位置跳动。
- 减少普通正文、图片回复和楼中楼预览的重复文字测量、解析与 Cell 重新配置；分页和页尾状态变化复用未改变的楼层内容。
- 只读权限检查合并请求，避免反复刷新所有可见楼层；动图播放复用解码源，按显示尺寸处理帧。
- 将播放进度与一般播放状态分开更新，减少无关语音/视频行刷新。
- 保留楼中楼两步回复、复制、图片和链接独立操作、缓存预载、阅读位置、搜索及淡蓝应用图标。已验证的 iOS 发帖/回复/上传链路保持不变。

## 版本与 SideStore 更新

- 发布标签：**v0.2.0beta7**；IPA 内 App 版本：**0.2.1**，Build **20**。
- 本版递增真实 App 版本，便于 SideStore 从旧版 0.2.0 检测到更新；不是只更改标签或源里的版本文字。
- 已添加源的用户刷新 Sources 后，可在 My Apps 检查 Update。签名刷新不等于自动安装新版；手动导入的旧 App 是否关联此源取决于 SideStore 的现有安装记录。
- 源地址：<https://raw.githubusercontent.com/othbradar/tiebalite-ios/main/sidestore/source.json>。源更新自动化从公开 Release 附件校验并提取真实版本、大小和 SHA256。

## 下载与安装

- 支持 iOS/iPadOS **18.0+**、iPhone/iPad、ARM64。
- 附件为完整真机 **Release 未签名 IPA**，需使用 SideStore 或既有工具自行签名；同时提供 SHA256SUMS。
- 沿用原 Apple ID/Team 和签名后 Bundle ID 覆盖安装，保留账号、草稿及缓存；不要先卸载旧版。

## 验证范围

- SF 修复的72项直接单元回归、iPhone/iPad共19项 UI 回归通过；P05复用、位移、阅读位置及回复目标回归保留。用户实机确认体验改善。
- 发布包重新按0.2.1/20做设备Release归档，检查完整资源、架构、版本、测试代码隔离和IPA完整性。没有新增生产手势、动画、overlay或依赖。
- 仍有部分模拟器采样短时尖峰，不宣称所有设备和场景绝无卡顿；未重跑全历史测试矩阵。已知全仓静态策略旧失败无新增，详细记录见[修复审计](https://github.com/othbradar/tiebalite-ios/blob/main/Docs/Audits/THREAD_SCROLL_FLUENCY_FIX_2026_10_23.md)。
- 其他既有功能限制沿用beta6说明；本轮不扩张服务端协议或私有SDK行为。
