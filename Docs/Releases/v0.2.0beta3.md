# TiebaLite iOS v0.2.0beta3 — 性能优化与首页修复

本版在 beta2 基础上包含已验收的 U06P1–U06P4 和三项首页改进，保留现有 Android TiebaLite 外观、阅读缓存、内容预载、原图查看及保存分享。

## 新功能

- 首页“经过贴吧”支持长按管理最近逛吧：长按任意吧显示各项右上角红色减号，点击删除对应本地访问记录，再长按隐藏减号。不会取消关注或删除帖子历史、缓存和阅读位置。
- 减号向右避开吧名，保留原有紧凑胶囊布局，不额外增加顶部留白。

## Bug 修复

- 修复进入吧首页时底部栏短暂占位、遮挡帖子的问题；返回首页仍正常显示底栏。
- 去掉吧首页下拉刷新时额外的“正在重新加载”说明栏，保留系统下拉刷新、旧内容及失败重试。
- 修复缓存重进后立即滑动时自动刷新可能替换阅读列表的问题：拖动、惯性滚动和深处阅读期间保留当前内容，回到顶部并停稳后应用更新。
- 修复 iPad 旋转进入分栏时初始阅读定位被系统 inset 调整提前取消、回到首楼的问题。已通过指定旋转/重进回归及正常 Live 多页帖子检查；完整真机与窗口尺寸矩阵仍未覆盖。

## 性能优化

- 缓存命中合并维护索引，纯 miss 不再写索引；保存阅读锚点不再读取旧正文。
- 图片先查磁盘，只有 miss 才进入下载队列；已有缓存图片不必等待其他下载。编码文件由有界写入队列持久化，保留请求合并、前台优先和取消隔离。
- 多页吧首页缓存改为单次合并；重复预取回调不再反复扫描全部楼层；仅阅读锚点变化时不再重复准备整份列表。
- 保留虚拟化、Cell 复用、稳定业务 ID 和既有恢复流程，未用清缓存或减少分页制造性能提升。

## 实测与验证范围

- 受控测试：30次页面缓存命中由30次索引写合并为1次；20次纯 miss 写0次；只改阅读锚点时旧正文读取0次。
- 受控测试：4个下载挂起时，磁盘已缓存图片仍能返回；两个消费者请求同一资源仍只有1次源下载，取消一个不影响另一个。
- 受控测试：五页共1000项缓存合并访问数2994→1000；30次重复预取只准备1份请求、源调用1次；30次锚点更新的全表准备次数31→1。
- 新增首页修复通过7项定向 Unit、5条 iPhone/iPad UI 流程及用户 Simulator 人工验收。U06P各批次沿用已验收的直接回归，计数不代表所有设备的FPS或耗时提升；本次未重复全量测试。

## 下载与安装

- 标签 `v0.2.0beta3`；App 版本 `0.2.0`，Build `4`。
- 支持 iOS/iPadOS 18.0 及以上，iPhone/iPad，arm64。
- 附件是**真机 Release 未签名 IPA**，沿用此前分发方式，安装前需自行签名；不是 Simulator、App Store 或 TestFlight 包。
- 使用 `SHA256SUMS` 核对下载文件；不包含账号、历史、缓存、草稿、测试 Fixture 或调试入口。

## 已知限制

- 真机相册及完整真机交互矩阵尚未验收，Development Team 未配置；Simulator 通过不等于真机通过。
- iPad 手工拖动窗口调宽本轮未得到有效 Live 样本，窄宽行为以定向 UI 回归为证，不承诺完整 Stage Manager 矩阵。
- 图片可选落盘队列达到上限时，该次资源可能未持久化；原图显示仍受4096像素解码预算限制，动图查看只保证静态帧，保存/分享保留取得的编码文件。
- URLSession逐字节接收和 Viewer 倍率更新两处条件性性能热点尚未测量，本版不声称已优化。私有接口与服务端审核仍可能变化。
- 不包含 U07 及后续阶段。
