# TiebaLite iOS v0.2.0beta4 — 回复回显、草稿与 iOS 发送改进

本版包含 beta3 之后已验收的内容操作与回复改进，保留现有界面、阅读位置恢复、内容缓存/预载、原图查看及保存分享。

## 新功能与改进

- 编辑器草稿按账号和发送目标保存，文字、表情和已选图片可在离开页面或重开 App 后继续编辑。
- 发帖、回复与图片上传接入已核对的 iOS 贴吧请求路径；支持文字与图片回复，GIF 上传准备保留原始动图编码。
- 发送成功后自动关闭编辑器，定向读取并显示新回复，无需下拉刷新；保留当前阅读位置和已缓存分页，重复成功回调不会重复读取或发送。
- 帖子分享、复制链接及正文内部链接使用现有系统入口；搜索、正文链接和已支持的 Scheme 入口正确传递来源。
- 分享、回复、点赞采用已验收的简洁空心图标；帖子内外图标与计数字号保持一致，分享显示数量或“分享”。

## Bug 修复

- 修复部分成功回复被误判为发送结果未知或验证要求，编辑器不能正常收起的问题。
- 修复成功读取新回复时，空分页信息导致“刷新失败”、仍需手动下拉的问题。
- 修复新回复缺少楼层号时正文和回复按钮过于靠左、点赞图标暂时缺失的问题；刷新前后正文位置一致。
- 修复手动刷新取消后续读取后可能阻止正常分页的问题，并保留账号切换、取消及缓存失效隔离。

## 验证范围

- 用户已实际确认文字评论、单张静态图片发送及最新回复即时回显正常。
- 沿用各次已验收候选的定向 Unit/UI 结果；最后样式修复通过 8 项相关 Unit、iPhone/iPad 各 1 项短 UI，覆盖无需下拉显示、缩进一致、点赞显示、阅读位置和编辑器收起。
- 发布包重新执行真机 Release 归档、测试/调试内容隔离、版本/架构/ZIP/校验和检查。未重复全量测试，未将 Simulator 结果表述为完整真机验收。

## 下载与安装

- 标签 `v0.2.0beta4`；App 版本 `0.2.0`，Build `17`。
- 支持 iOS/iPadOS 18.0 及以上，iPhone/iPad，arm64。
- 附件为**真机 Release 未签名 IPA**，安装前需自行签名；不是 Simulator、App Store 或 TestFlight 包。Development Team 仍未配置。
- 附带 `SHA256SUMS`。发布包不包含用户账号、历史、草稿、缓存、测试 Fixture 或调试入口。
- 保留原签名身份及 Bundle ID 覆盖安装，避免为升级主动卸载或清理数据。

## 已知限制

- 不宣称与官方 iOS 客户端完全一致：SDK/Passport 与相关安全验证按约定暂不接入，接口可用性与服务端审核结果仍由服务端决定。
- 原图/透明 PNG、完整压缩与图片元数据策略、正文图片混排、提前/并发上传、可配置水印等仍有差异。GIF 保留编码已通过离线测试，真实服务端动画、多图及各类回复目标仍需分别验收。
- 增量接口没有返回楼层号时先留空，正常页面返回后补齐，不猜造楼层编号。
- 完整真机、相册及 iPad Stage Manager 窗口矩阵未覆盖；既有图片显示解码预算与动图静态显示限制保持。
