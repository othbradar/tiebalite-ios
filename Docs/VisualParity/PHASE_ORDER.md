# 阶段顺序

| 阶段 | 内容 | 用户能看到的成果 |
|---|---|---|
| R00 | 锁定 Android UI 参考、截图与人工验收工具 | 当前版本基线截图、对照矩阵 |
| R01 | 真实头像/吧图/等级数据管线与统一视觉原子 | 组件画廊：头像、等级、分割线、图片网格 |
| R02 | 根 Shell 改为首页/动态/消息/我的 | 四个底部入口、移除重复大标题 |
| R03 | 首页：最近浏览 + 关注吧 | 原版首页布局、真实吧图、热度、等级 |
| R04 | 动态/推荐信息流 | 头像、时间、正文摘要、多图、吧标签、动作栏 |
| R05 | 吧首页 | 真实吧头、排序、精华/分类横滑页、平面帖子流 |
| R06 | 帖子阅读视觉 | 平面楼层、头像等级、图片网格、前三条楼中楼 |
| R07 | 官方贴吧表情 | `#滑稽` 等在阅读面正确显示 |
| R08 | 完整楼中楼页 | 点击“查看全部”进入分页楼中楼 |
| R09 | 文字发帖与回复 | 新帖、回复主题/楼层/楼中楼；用户手工决定是否发送 |
| R10 | 图片上传与表情选择器 | 图片回复、贴吧表情面板、草稿 |
| R11 | 消息 | 回复我的/提到我的横滑页、未读角标、深链 |
| R12 | 我的页和全局视觉复核 | 原版个人页层级、全局头像/等级/分割线一致 |
| R13 | 最终集成和 Beta Release | 全链路、最终完整质量门禁、可选 IPA |

## 不允许跳阶段的依赖

- R01 是所有头像、等级、图片网格的基础。
- R02 必须早于 R03、R04、R11、R12。
- R06 必须早于 R08、R09。
- R07 必须早于 R10。
- R09 只先完成文字写入；R10 再增加图片和表情面板。
- 每个阶段必须先由用户看 Simulator，再提交。
