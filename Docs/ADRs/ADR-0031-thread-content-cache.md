# ADR-0031：帖子和楼中楼按页缓存与阅读位置

- 状态：U03 用户接受；规定范围恢复已通过，iPad 旋转分栏回首楼作为已知缺陷保留
- 日期：2026-10-03
- 基线：9248f2dc68a0610076178f2189a329d4a8bc5c6d

沿用 ADR-0030 的 ContentPageCache。生产 composition 为吧首页、帖子和楼中楼共享同一个实例和磁盘目录；没有第二套容量、磁盘索引或清理引擎。仍使用已验收的 VirtualizedList、系统导航和唯一 MediaViewer。

CachedReadingRepository 只负责阅读领域页和小型 manifest。页键包含本地非凭证账号 namespace、threadID、可选父 postID、query、PBPage pn/pid（楼中楼为 PBFloor page/parent）和内容摘要。manifest 保存页来源、时间和 ReadingPosition（身份、稳定 postID、原始页定位）。成功页面编码一次；滚动停稳/离开/后台只写引用和位置，不编码渲染行或整帖。现有浏览历史负责入口及展示记录，预取不增加历史；通知预定位使用不写进度的入口。

新实例从实际存在的连续页范围恢复，优先包含阅读位置的范围；中间页面被 LRU 清理时不伪造前缀，不逐页联网追赶。下一页始终使用末页保存的原始 hasMore/pid。缺页及网络失败保留已读内容，页尾提供重试。系统可清理 Caches，未命中仍沿现有首屏加载路径。

新鲜期为 5 分钟，保留期、页大小和总预算复用 U02。过期先显示后复查当前阅读页；主动下拉及发送成功回调也刷新当前页，保留其他已加载页和稳定锚点。普通分页仍增量追加；当前页重查只重配置发生变化的稳定行，不重建导航树。同实例不重复 scrollTo，不增加行内偏移恢复。

显式 authentication、HTTP 401/403/404/410 更新既有不可用状态并失效副本；未知服务端 code 不推断为删帖。普通离线/超时/解码失败保留成功副本。账号 context/revision 和 cache epoch 拒绝旧请求与 checkpoint。内容中已由 mapper 确证的不可用标记沿领域模型处理，不新增猜测 API 参数或错误码。

缓存提示仅复用页尾的文字与重试入口，不增加顶部通知、overlay、自定义动画或手势。图片字节仍由现有图片服务处理，正文持久化不承诺所有图片可离线加载（U06 范围）。

首次恢复采用已批准的一次性定位与独立当前视口保持：实际显示的目标 Cell 通过身份/配置/视口检查后释放历史目标；后续布局只保持当前阅读位置，用户滚动更新锚点，正常进度不再受初始事务抑制。旧的等待前置行测量协议已替换，不将 fitting 结果当作全局布局完成。430001 恢复、自动退出、470001 新位置保存、Live 重进/进程重启以及规定的 iPad 重进已通过，完整候选已覆盖安装并由用户批准提交。

iPad 旋转进入分栏后详情回首楼仍未修复；失败用例和证据保留，用户明确允许不阻塞 U04，但不将其标记为通过，也不在 U04 顺手修改导航或旋转恢复。详见 TASK_STATE。
