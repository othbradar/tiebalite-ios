# ADR-0039: iOS 点赞与本人内容删除

- 状态：U14 USER_ACCEPTED，用户授权本地提交；2026-10-17。真实点赞已由用户回验，全部真实删除场景仍未验证。
- 决策依据：本轮 U14 授权、用户“原版 iOS”约束、22.11.1 本地参考二进制。发送/上传链路及已验收外观保持冻结。

## 行为与边界

复用现有空心点赞图标、字号、间距和点击区域，按钮请求期间禁用。首次动作先通过独立原版 iOS PBPage 读取当前账号/目标/点赞状态，然后一次 opAgree。原版 currentOperate=1 增加赞且对应 op_type=0；撤销为 op_type=1。主题 obj_type=3，普通楼层=1（2026-10-17 根据 Live 错误3280005及原版调用分支纠正；2是另一FP特殊分支）。未实现点踩或子回复点赞。

删除入口仅对当前登录 UID 与缓存作者 UID 一致的候选做只读检查；缓存只是候选筛选。成功解析的新鲜 iOS 响应须匹配线程和内容 ID、当前账号 UID、作者 UID、吧 ID，并排除已删除/不可删除标记。对应原版作者权限判断，服务端最终校验仍不可替代。授权未知不展示删除；不按昵称授予权限，不提供吧务删除他人内容。确认框分别使用“删除主题 / 删除此楼 / 删除子回复”；用户确认后重新检查归属再提交一次。没有自动重试、没有代理 Live 写入。

所有动作实例独立于 NativeWriteAppService。共用已验证纯编码/签名/HTTP 工具及只读账号/TBS 准备，但不修改其基线、运行时、草稿、发帖/回复、上传或成功回显。Metadata UID 请求按会话合并；切号取消任务，迟到结果不发布到另一账号。

## 删除后的本地状态与缓存

只在成功回执及本地持久化完成后更新已删除的公开目标 ID 集合。小型 Application Support 文件最多 4096 项，容量/可写检查失败时不提交删除；不会为腾空间丢弃旧记录。此集合代表已经删除的公共内容，不包含凭证、内容或作者信息，跨登录保留。它不是本地屏蔽功能，不会上传任何历史记录。

列表根据稳定业务 ID 局部过滤并修正计数，导航栈、offset、分页游标不重建。父楼展示记录与删除记录保留时间戳；删除前三条预览之外的子回复也更新旧父楼总数，新读到的服务端总数不重复扣减。共享字节缓存新增独立的删除准入规则：带已删条目的线程页、楼中楼页、回复 delta、吧列表页、个人主题/回复页不再读取/落盘，早于子回复删除的父楼缓存也失效；清除缓存不清除已删除记录。小型 manifest/阅读位置保留。已有页面返回或迟到预载也通过可见性投影再次过滤；不用修改冻结的 CachedReadingRepository 回复合并逻辑。规则更新有单独 revision，中途跨 revision 的缓存读取/写入不会命中发布。

点赞失败保留原计数；没有乐观改数。超时/不完整回执视为未知；下一次点点赞只读取状态，不重复提交。删除结果未知保留页面和草稿、停止本次删除入口，用户自行核对。若远端已成功但本地记录落盘失败，同样报告结果未知，不宣称本地同步完成。

## 交互与限制

无新增手势、导航动画、透明遮罩、依赖。仅新增系统确认/结果 alert。列表 UIHostingConfiguration 显式传递动作服务，避免独立 cell 丢失环境。真实请求是否获服务端接受需用户在指定自有内容上验证；离线测试不代表服务端审核/SDK 完整对齐。未知的 SDK/Passport 身份不伪造。
