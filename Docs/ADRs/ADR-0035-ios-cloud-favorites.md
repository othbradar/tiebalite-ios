# ADR-0035 — U10 原生 iOS 云端收藏与同步

- 日期：2026-10-12。用户明确追加云端收藏与同步，覆盖 ADR-0034 的本机降级范围；本机书签保留，不自动上传，不混入浏览历史。
- 参考：用户提供的 iOS 22.11.1 TBClient，SHA256 `4f0cb74c738f714258dd14bde5fb7a7859ab7baf19183c01e900704ab702d9eb`。原生 TBCFavoriateModel 和 TBCMarkItem 字段/调用路径见 API_EVIDENCE 新节。收藏不复用 Android 写入或修改现有发帖链路。
- 边界：独立 typed FavoriteRepositoryProtocol，普通 HTTPS form/JSON；使用已验证的 iOS Common/表单编码/签名纯函数及独立 Runtime 实例。登录凭据由当前会话授权，公开账号 ID 与会话代次绑定；只读复用本 App 已准备的同账号 TBS，没有时点击写入后只获取 TBS，不触发登录/回复/上传，不写发送回执。缺失的私有 SDK 输出保持缺失，不声称全客户端逐字节等同。
- 云端为收藏的持久化真相。列表每页20条，服务端顺序、稳定 threadID 去重；重开、前台恢复、下拉刷新重读第一页。保留旧内容直至读成功；失败可重试。第一页刷新替换旧云端快照，反映其他客户端的添加/取消/楼层变化，不拿本地快照回写服务器。不递归遍历全部收藏。
- 添加/取消只响应用户明确点击，串行防重复，无自动重试、无乐观成功；业务码明确0才更新 UI。网络/畸形回执保留原状态，告知刷新检查，避免重复写。操作后分页游标标记失效，下次请求更多先同步第一页，防止删除/前插造成 offset 跳项。账号变化取消任务并立即清空展示；即使底层不响应取消，代次与会话校验也拒绝旧结果。
- 收藏使用 mark_pid，max_pid/post_no 表示最新楼层，禁止作保存位置。当前入口按 U09 的普通顺序明确定位指定 pid（status1），历史不能覆盖；原服务器 mark_status 保留在模型里，热门等本 App 未支持阅读模式不自动套用。无法定位/已删除有既有错误页或原生提示。
- 复用更多菜单、楼层回复长按菜单、我的页列表与原生系统提示；无新常驻说明栏、动画、手势、overlay、依赖、数据库。云端收藏不依赖临时内容缓存，也不改变其容量/预载/阅读位置。
- 验证：只执行定向 Unit/UI 与 COMMON 轻量门禁。真实收藏/取消只能用户点击；代理可只读同步收藏，不扫描其他 App 数据，不实发帖子。
