# Fixture catalog

All files in this directory are sanitized for deterministic tests. They contain no
captured Tieba response, user account, Cookie, token, device identifier, private
text or third-party media.

- `API/Recommendations/personalized_cross_language.pb`: generated by the tracked
  JVM `DynamicMessage` producer from the pinned Android Proto descriptor closure.
  It is `CROSS_LANGUAGE_GENERATED`, not live runtime evidence.
- `API/Search/*.json`: synthetic Hybrid JSON payloads for forum/thread result
  decoding, stable-ID deduplication, and thread pagination. They are not captured
  server responses and do not contain a real query or user content.
- `JSON/success.json`: valid JSON decoding path.
- `JSON/malformed.json`: deterministic malformed JSON path.
- `Binary/opaque.pb`: opaque bytes for the binary fixture loading path. No schema
  endpoint provenance or Tieba field meaning is claimed; it remains a synthetic
  loader fixture.
- `Images/pixel.svg`: original 1×1 synthetic SVG for image resource loading.
- `Text/hash-mismatch.txt`: deterministic hash mismatch path.

`manifest.json` records the format, source, purpose, sanitization status and
SHA-256 for every fixture entry.
